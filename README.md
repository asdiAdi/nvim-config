# 💤 LazyVim

My Neovim setup for web work. Based on [LazyVim](https://github.com/LazyVim/LazyVim).

## Install

```bash
git clone https://github.com/anomalyco/nvim-config.git ~/.config/nvim
nvim
```

Open nvim and everything sets itself up. Open a file and give it a minute
the first time while it downloads what it needs.
